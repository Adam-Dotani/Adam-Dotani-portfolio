# Portfolio Website

A full-stack portfolio and blog application built using PHP, MySQL,
Apache and Docker.

## Features

- Responsive personal portfolio
- Database-backed blog
- Secure administrator authentication
- Password hashing with PHP's password API
- Prepared SQL statements
- Dockerized PHP and Apache environment
- Cloud deployment with Railway
- Managed MySQL database

## Technology

- PHP 8
- MySQL
- Apache
- HTML
- CSS
- JavaScript
- Docker
- Railway

 https://adam-dotani-portfolio-production.up.railway.app

## Local Setup with XAMPP

1. Place the project inside `htdocs`.
2. Create the MySQL database.
3. Import `database_setup.sql`.
4. Start Apache and MySQL.
5. Open the project through localhost.
